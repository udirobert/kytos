Source → pocket: delete one edge

A signal starts at KRAS's P-loop and walks the contact graph. Does the wiring change what reaches the distant pocket? We took a disclosed four-supernode slice of the KRAS core recorded in chapter 1, ran it as a continuous-time quantum walk, and compared it with the same graph with one edge removed — two independent two-qubit walks in one four-qubit Qiskit circuit, one job.

  • The slice, readout node and time were chosen knowing where the pocket is. This is an explanatory demo, not blind site prediction.
  • {{ r.backend }} here is a remote noise-model simulator, not physical IonQ hardware. It is one run with no confidence interval.
  • The classical walk is a different dynamic, not a weaker predictor. No quantum advantage is claimed.

The real test: freeze graph construction, sources, time aggregation and readouts first. Then run every eligible apo protein in a declared panel against classical diffusion, graph distance/degree and rewired or decoy-pocket controls, and report failures. A negative result is still a result.
