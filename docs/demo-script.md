**Canonical script** — merges the VEED/Fabric front-load ([`observatory.md §7`](observatory.md#7-demo-script-2-minutes))
with the self-own credibility beat. **No PowerPoint** — the live site is the deck.

Record against the **live Netlify URL** ([kytosapp.netlify.app](https://kytosapp.netlify.app));

## 0:00–0:10 — Hook: the leaderboard lies

> "Virtual cell models score well but fail biologically — and the leaderboard
> only shows numbers. Arc says the field needs people who know when a model is
> wrong for *biological* reasons. We built the thing that catches us — in public,
> for the next 78 days."

**On screen:** Home → hover "Why the Observatory" panel → click through to k001 run detail.

---

## 0:10–0:35 — The newsroom broadcast (VEED + fal beat)

> "This is the Kytos Newsroom — run #1 of 78. The cell is generated by VEED
> Fabric on fal, from the same committed facts JSON — same numbers, same flags.
> It opens with Tavily field research — what the field is saying — then it
> confesses our own audit flags, and it signs off by **singing the Run #1
> anthem**, composed by ElevenLabs Music from our own lyrics. One command
> regenerates the whole broadcast from committed facts."

**On screen:** Let **briefing video autoplay 10–14 seconds** (muted loop) —
land on the "kytos newsroom · run #1 of 78 · the cell speaks" stamp. If the
anthem is audible, unmute for 3–4 seconds at the song — it's the memorable
close. Do not talk over the opening frame.

**If no `briefing.mp4` yet:** show vessel instrument + say: "Fabric pipeline is wired — script, TTS, fal image, `veed/fabric-1.0`; we're landing the first mp4 before submission." Then move on at 0:25 — do not dwell.

## 0:30–0:55 — Self-own: our vessel confesses

> "This is κύτος — the hollow vessel. Run k001 is our own baseline. **It fails
> our audit**: housekeeping genes shifted +2.10 log2FC — past our threshold.
> Interferon response is mixed-directional. We flagged ourselves. That's the
> product: every run publishes failure modes, not just scores."

**On screen:** Vessel instrument (fill = ceiling headroom, cracks = warnings) → confession banner → audit flag cards (ACTB/GAPDH, ISG15/IFIT1/MX1/OAS1).

---

## 0:55–1:30 — Metrics vs ceiling → provenance

> "Metrics come from `cell-eval` — nothing here is LLM-generated. Scores vs
> noise-adjusted ceiling; every headline value links to the committed CSV.
> Click a value — that's the source. Chart, flags, reproduce command — all
> trace to artifacts in the repo."

**On screen:** Plotly metrics vs ceiling → click metric → CSV opens → scroll provenance footer (commit, seed, reproduce command).

---

## 1:30–1:55 — Literature + narrative + NER (partner rails)

> "Each flag gets literature — Tavily pulls evidence for flagged genes. Pioneer
> fine-tuned GLiNER2 extracts biomedical entities from that text — genes,
> pathways, cell types — deterministically, no hallucinated symbols. The
> narrative digest is rendered *from* facts only; every sentence cites its
> source field. Numbers by code; prose by LLM; entities by encoder; never the
> other way around. We pre-registered hypotheses before touching the leaderboard."

**On screen:** Literature rail → scroll to **Biomedical NER** (fine-tuned LoRA badge,
entity chips per gene, entity count in hero strip) → narrative block (or fallback
digest — say "deterministic fallback if API is down; site still builds") → hypotheses list.
